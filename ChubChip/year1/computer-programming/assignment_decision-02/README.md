# Decision Assignment II

## ข้อ 6

จงเขียนโปรแกรมรับจำนวนเต็ม 2 จำนวน หากจำนวนทั้งสองเป็นบวกทั้งคู่ ให้พิมพ์คำว่า `"Positive"`

### Input

- จำนวนเต็ม 2 จำนวน

### Output

- `Positive` หากจำนวนทั้งสองเป็นบวก

ไฟล์โปรแกรม: `06_both_positive.cpp`

## ข้อ 7

จงเขียนโปรแกรมรับจำนวนเต็ม 1 จำนวน หากเป็นบวก ให้พิมพ์คำว่า `"Positive"` หากเป็นลบให้พิมพ์คำว่า `"Negative"` หากเป็นศูนย์ให้พิมพ์คำว่า `"Zero"`

### Input

- จำนวนเต็ม 1 จำนวน

### Output

- `Positive` หากค่าที่รับเข้ามาเป็นบวก
- `Negative` หากค่าที่รับเข้ามาเป็นลบ
- `Zero` หากค่าที่รับเข้ามาเป็นศูนย์

ไฟล์โปรแกรม: `07_number_sign.cpp`

## ข้อ 8

จงเขียนโปรแกรมรับจำนวนเต็ม 2 จำนวน หาผลบวกเลขทั้งสอง หากผลบวกเป็นบวก ให้พิมพ์คำว่า `"Positive"` หากผลบวกเป็นลบ ให้พิมพ์คำว่า `"Negative"` หากผลบวกเป็นศูนย์ ให้พิมพ์คำว่า `"Zero"`

### Input

- จำนวนเต็ม 2 จำนวน

### Output

- `Positive` หากผลบวกเป็นบวก
- `Negative` หากผลบวกเป็นลบ
- `Zero` หากผลบวกเป็นศูนย์

ไฟล์โปรแกรม: `08_sum_sign.cpp`

## ข้อ 9

จงเขียนโปรแกรมรับคะแนนสอบภาษาอังกฤษ หากได้คะแนน 850 ขึ้นไป แสดงผลสอบ “ผ่านยอดเยี่ยม” หากได้คะแนน 650 ขึ้นไป แต่ไม่ถึง 850 แสดงผลสอบ “ผ่าน” หากต่ำกว่า 650 แสดงผลสอบ “ไม่ผ่าน”

### Input

- คะแนนสอบภาษาอังกฤษ

### Output

- `ผ่านยอดเยี่ยม` หากได้คะแนน 850 ขึ้นไป
- `ผ่าน` หากได้คะแนน 650 ขึ้นไป แต่ไม่ถึง 850
- `ไม่ผ่าน` หากได้คะแนนต่ำกว่า 650

ไฟล์โปรแกรม: `09_english_exam_result.cpp`

## ข้อ 10

จงเขียนโปรแกรมรับค่าจำนวนจริง 2 จำนวน แล้วหาผลหาร โดยจำนวนแรกเป็นตัวตั้ง จำนวนที่ 2 เป็นตัวหาร หากตัวหารเป็น 0 ให้แจ้งข้อความว่า `"Cannot Divide by Zero."`

### Input

- จำนวนจริง 2 จำนวน
- จำนวนแรกเป็นตัวตั้ง
- จำนวนที่สองเป็นตัวหาร

### Output

- ผลหารของจำนวนทั้งสอง
- `Cannot Divide by Zero.` หากตัวหารมีค่าเท่ากับ 0

ไฟล์โปรแกรม: `10_division_by_zero.cpp`
