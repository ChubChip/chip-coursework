# Decision Assignment III

## ข้อ 11

จงเขียนโปรแกรมรับอักษร 3 ครั้ง ถ้าเป็น A มีค่าเป็น 10 ถ้าเป็น B มีค่าเป็น 20 และถ้าเป็น C มีค่าเป็น 30 จากนั้นหาผลรวมและแสดงผล

### Input

- อักษรจำนวน 3 ตัว

### Output

- ผลรวมของค่าที่กำหนดให้กับอักษรแต่ละตัว

ไฟล์โปรแกรม: `11-character_value_sum.cpp`

## ข้อ 12

จงเขียนโปรแกรมเครื่องคิดเลขอย่างง่าย รับเลข 2 จำนวน และรับเครื่องหมายเป็นอักษร 1 ตัว (+ - * / %) คำนวณผลลัพธ์และแสดงผล

### Input

- ตัวเลข 2 จำนวน
- เครื่องหมายทางคณิตศาสตร์ 1 ตัว ได้แก่ `+`, `-`, `*`, `/`, `%`

### Output

- ผลลัพธ์จากการคำนวณ

ไฟล์โปรแกรม: `12-simple_calculator.cpp`

## ข้อ 13

จงเขียนโปรแกรมรับวิธีจ่ายเงิน และยอดเงินค่าสินค้า และคำนวณเงินรวมค่าสินค้าที่ลูกค้าต้องจ่าย หากลูกค้าชำระเป็นเงินสด ให้ส่วนลด 10% หากชำระเป็นเช็คคิดราคาปกติ หากชำระด้วยบัตรเครดิต คิดเพิ่ม 5%

### Input

- วิธีจ่ายเงิน
- ยอดเงินค่าสินค้า

### Output

- เงินรวมค่าสินค้าที่ลูกค้าต้องจ่าย

### เงื่อนไขการคำนวณ

- เงินสด: ลดราคา 10%
- เช็ค: คิดราคาปกติ
- บัตรเครดิต: คิดเพิ่ม 5%

ไฟล์โปรแกรม: `13-payment_method_total.cpp`

## ข้อ 14

จงเขียนโปรแกรมรับชั่วโมงจอดรถ และประเภทรถ และคำนวณเงินค่าจอดรถ หากเป็นรถยนต์คิดชั่วโมงละ 10 บาท รถบัสคิดชั่วโมงละ 15 บาท รถบรรทุกคิดชั่วโมงละ 20 บาท รถอื่นๆ คิดชั่วโมงละ 5 บาท

### Input

- จำนวนชั่วโมงที่จอดรถ
- ประเภทรถ

### Output

- เงินค่าจอดรถ

### อัตราค่าจอดรถ

- รถยนต์: ชั่วโมงละ 10 บาท
- รถบัส: ชั่วโมงละ 15 บาท
- รถบรรทุก: ชั่วโมงละ 20 บาท
- รถอื่นๆ: ชั่วโมงละ 5 บาท

ไฟล์โปรแกรม: `14-parking_fee.cpp`

## ข้อ 15

จงเขียนโปรแกรมรับรับคะแนนสอบ กับโครงงาน นำมาตัดเกรด หากคะแนนสอบ 70 ขึ้นไป และส่งโครงงาน ผลสอบจะผ่าน (Pass-P) หากคะแนนสอบ 70 ขึ้นไป แต่ไม่ส่งโครงงาน ผลสอบจะไม่สมบูรณ์ (Incomplete-I) หากคะแนนสอบน้อยกว่า 70 ผลสอบจะตก (Fail-F)

### Input

- คะแนนสอบ
- สถานะการส่งโครงงาน

### Output

- `Pass-P` หากคะแนนสอบ 70 ขึ้นไปและส่งโครงงาน
- `Incomplete-I` หากคะแนนสอบ 70 ขึ้นไปแต่ไม่ส่งโครงงาน
- `Fail-F` หากคะแนนสอบน้อยกว่า 70

ไฟล์โปรแกรม: `15-grade_evaluation.cpp`
