# Assignment - For Loop

แบบฝึกหัดการใช้คำสั่งวนซ้ำ `for`

## ข้อ 1: หาผลรวมและค่าเฉลี่ย

ให้รับข้อมูลจากคีย์บอร์ด 10 จำนวน หาผลรวมและค่าเฉลี่ย พิมพ์ผลลัพธ์ผลรวมและค่าเฉลี่ย

### Input

- ตัวเลขจำนวน 10 ค่า

### Output

- ผลรวมของตัวเลขทั้ง 10 ค่า
- ค่าเฉลี่ยของตัวเลขทั้ง 10 ค่า

ไฟล์โปรแกรม: `01-sum_and_average.cpp`

## ข้อ 2: ตรวจสอบเลขคู่และเลขคี่

ให้รับข้อมูลจากคีย์บอร์ด 10 จำนวน ตรวจสอบว่าเป็นเลขคู่ (even) หรือเลขคี่ (odd) และหาผลรวมเลขคู่และผลรวมเลขคี่ พิมพ์ผลลัพธ์ผลรวมเลขคู่ และผลรวมเลขคี่

### Input

- ตัวเลขจำนวน 10 ค่า

### Output

- ผลรวมเลขคู่
- ผลรวมเลขคี่

ไฟล์โปรแกรม: `02-even_odd_sum.cpp`

## ข้อ 3: นับจำนวนที่ไม่เป็นศูนย์

ให้รับข้อมูลจากคีย์บอร์ด 10 จำนวน และนับจำนวนที่ไม่เป็นศูนย์

### Input

- ตัวเลขจำนวน 10 ค่า

### Output

- จำนวนข้อมูลที่มีค่าไม่เท่ากับศูนย์

ไฟล์โปรแกรม: `03-count_nonzero.cpp`

## ข้อ 4: นับจำนวนบวก ลบ และศูนย์

ให้รับข้อมูลจากคีย์บอร์ด 10 จำนวน และนับว่ามีจำนวนที่เป็นบวก จำนวนที่เป็นลบ และจำนวนที่เป็นศูนย์ พิมพ์ผลลัพธ์จำนวนที่เป็นบวก จำนวนที่เป็นลบ และจำนวนที่เป็นศูนย์

### Input

- ตัวเลขจำนวน 10 ค่า

### Output

- จำนวนข้อมูลที่เป็นบวก
- จำนวนข้อมูลที่เป็นลบ
- จำนวนข้อมูลที่เป็นศูนย์

ไฟล์โปรแกรม: `04-count_positive_negative_zero.cpp`

## ข้อ 5: ตัดเกรดนักศึกษา

ให้รับคะแนนสอบนักศึกษาจากคีย์บอร์ด 10 คน ตัดเกรด พิมพ์ผลลัพธ์คะแนนสอบและเกรด (กำหนดรายละเอียดและวิธีการตัดเกรดตามความเหมาะสม)

### Input

- คะแนนสอบของนักศึกษา 10 คน

### Output

- คะแนนสอบของนักศึกษาแต่ละคน
- เกรดของนักศึกษาแต่ละคน

ไฟล์โปรแกรม: `05-student_grades.cpp`

## สิ่งที่ได้ฝึก

- การรับข้อมูลหลายค่า
- การสะสมผลรวม
- การนับจำนวนตามเงื่อนไข
- การใช้คำสั่งเงื่อนไขร่วมกับลูป
