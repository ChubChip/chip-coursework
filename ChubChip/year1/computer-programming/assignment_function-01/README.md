# Assignment - Function I

จงเขียนโปรแกรม โดยให้มีฟังก์ชัน ดังนี้

- ฟังก์ชันรับข้อมูลจากคีย์บอร์ดตามโจทย์ และส่งไปยังฟังก์ชัน `main` (มีได้มากกว่า 1 ฟังก์ชัน)
- ฟังก์ชันรับข้อมูลจากฟังก์ชัน `main` เพื่อประมวลผลตามโจทย์ และส่งผลลัพธ์กลับไปยังฟังก์ชัน `main` (มีได้มากกว่า 1 ฟังก์ชัน)
- ฟังก์ชันรับข้อมูลจากฟังก์ชัน `main` เพื่อแสดงผลลัพธ์ตามโจทย์
- ฟังก์ชันอื่นๆ ตามความเหมาะสม เช่น ฟังก์ชันพิมพ์หัวเรื่อง ชื่อ-นามสกุลผู้เขียนโปรแกรม วันที่เขียนโปรแกรม

## ข้อ 1: คำนวณเปอร์เซ็นต์คะแนนสอบ

จงเขียนโปรแกรมคำนวณเปอร์เซ็นต์คะแนนสอบดังนี้

- รับคะแนนสอบ และคะแนนเต็ม เป็นจำนวนทศนิยม จากคีย์บอร์ด
- คำนวณเปอร์เซ็นต์จากคะแนนสอบ  
  `เปอร์เซ็นต์ = 100 * คะแนนสอบ / คะแนนเต็ม`
- พิมพ์ผลลัพธ์ คะแนนสอบ คะแนนเต็ม และเปอร์เซ็นต์

### ข้อมูลที่รับเข้า

- คะแนนสอบ
- คะแนนเต็ม

### ผลลัพธ์ที่แสดง

- คะแนนสอบ
- คะแนนเต็ม
- เปอร์เซ็นต์คะแนนสอบ

ไฟล์โปรแกรม: `01-exam_percentage.cpp`

## ข้อ 2: คำนวณราคาสินค้าและภาษี

จงเขียนโปรแกรมคำนวณราคาสินค้าดังนี้

- รับจำนวนสินค้า เป็นจำนวนเต็ม จากคีย์บอร์ด และรับราคาสินค้า เป็นจำนวนทศนิยม จากคีย์บอร์ด
- คำนวณยอดเงินค่าสินค้า  
  `ยอดเงินค่าสินค้า = จำนวนสินค้า * ราคาสินค้า`
- คำนวณภาษี  
  `ภาษี = ยอดเงินค่าสินค้า * 7/100`
- คำนวณยอดเงินทั้งหมด  
  `ยอดเงินทั้งหมด = ยอดเงินค่าสินค้า + ภาษี`
- พิมพ์ผลลัพธ์ ยอดเงินค่าสินค้า ภาษี และยอดเงินทั้งหมด

### ข้อมูลที่รับเข้า

- จำนวนสินค้า
- ราคาสินค้า

### ผลลัพธ์ที่แสดง

- ยอดเงินค่าสินค้า
- ภาษี
- ยอดเงินทั้งหมด

ไฟล์โปรแกรม: `02-product_price_tax.cpp`

## ข้อ 3: คำนวณยอดเงินที่ต้องการกู้ กยศ.

จงเขียนโปรแกรมคำนวณยอดเงินที่ต้องการกู้ กยศ. ดังนี้

- รับค่าลงทะเบียนต่อภาคเรียน ค่าเช่าหอพักต่อเดือน ค่าใช้จ่ายส่วนตัวต่อเดือน จากคีย์บอร์ด
- คำนวณยอดเงินที่ต้องการกู้ทั้งปี ได้แก่ ค่าลงทะเบียน 2 ภาคเรียน ค่าเช่าหอพัก 12 เดือน และค่าใช้จ่ายส่วนตัว 12 เดือน
- พิมพ์ผลลัพธ์ ค่าลงทะเบียนต่อภาคเรียน ค่าเช่าหอพักต่อเดือน ค่าใช้จ่ายส่วนตัวต่อเดือน และจำนวนเงินทั้งหมดที่ต้องการกู้

### ข้อมูลที่รับเข้า

- ค่าลงทะเบียนต่อภาคเรียน
- ค่าเช่าหอพักต่อเดือน
- ค่าใช้จ่ายส่วนตัวต่อเดือน

### ผลลัพธ์ที่แสดง

- ค่าลงทะเบียนต่อภาคเรียน
- ค่าเช่าหอพักต่อเดือน
- ค่าใช้จ่ายส่วนตัวต่อเดือน
- จำนวนเงินทั้งหมดที่ต้องการกู้ต่อปี

ไฟล์โปรแกรม: `03-student_loan.cpp`

## โครงสร้างฟังก์ชัน

โปรแกรมควรแบ่งการทำงานออกเป็นฟังก์ชัน เช่น

- ฟังก์ชันรับข้อมูล
- ฟังก์ชันคำนวณผลลัพธ์
- ฟังก์ชันแสดงผลลัพธ์
- ฟังก์ชันแสดงหัวเรื่องหรือข้อมูลโปรแกรม
