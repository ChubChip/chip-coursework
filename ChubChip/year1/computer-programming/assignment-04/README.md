# Assignment4 - Computer Programming 1/2566

จงเขียนโปรแกรมต่อไปนี้

## โจทย์

ร้านเบเกอรี่ รับทำเค้กตามสั่ง ต้องการคำนวณจำนวนวัตถุดิบที่ต้องใช้ในการทำเค้ก และจำนวนเค้กที่ต้องทำให้เพียงพอกับจำนวนที่ลูกค้าสั่ง โดยให้มีเศษเหลือน้อยที่สุด ในการทำเค้กจะมีสูตรในการทำ โดยสูตร 1 สูตรจะได้เค้ก 1 ปอนด์

เค้กที่ทำขายลูกค้า แต่ละก้อนมีขนาด 2 ปอนด์ ตัดเป็นชิ้นได้จำนวน 8 ชิ้น หากลูกค้าสั่ง 20 ชิ้น จะต้องทำเค้กจำนวน 3 ก้อน (ก้อนละ 2 ปอนด์ รวม 6 ปอนด์) ซึ่งจะตัดได้ 24 ชิ้น และจะมีเค้กเหลือจำนวน 4 ชิ้น ดังนั้นทางร้านจึงต้องเตรียมวัตถุดิบในการทำเค้กสำหรับ 6 สูตร หรือ 6 ปอนด์

จงเขียนโปรแกรมเพื่อคำนวณจำนวนสูตรที่ต้องใช้ จำนวนก้อนเค้กที่ต้องทำ จำนวนชิ้นที่ได้ และจำนวนชิ้นที่เหลือ โดยรับจำนวนชิ้นที่ลูกค้าสั่งจากคีย์บอร์ด เช่น จากตัวอย่างข้างต้น

## Input

จำนวนชิ้นที่ลูกค้าสั่ง : 20

## Output

จำนวนสูตรที่ใช้ : 6

จำนวนก้อน : 3

จำนวนชิ้นที่ได้ : 24

จำนวนชิ้นที่เหลือ : 4
