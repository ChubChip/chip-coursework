เขียนโปรแกรมต่อไปนี้ โดยแต่ละโปรแกรมให้มีฟังก์ชันตามที่โจทย์กำหนด ให้วิเคราะห์โจทย์เพื่อออกแบบการทำงานของฟังก์ชันในโจทย์แต่ละข้อให้เหมาะสม ทั้งนี้ calling function อาจเป็นฟังก์ชันใดๆ ที่ไม่ใช่ฟังก์ชัน `main` ก็ได้

## ข้อ 1: คำนวณเงินทอน

จงเขียนโปรแกรมรับจำนวนสินค้า (`amount`) และราคาต่อหน่วย (`price`) โดยจำนวนสินค้าและราคาต่อหน่วยต้องมีค่ามากกว่า 0 และคำนวณเงินรวม

```text
total = amount * price
```

จากนั้นรับจำนวนเงินที่จ่าย (`expense`) ซึ่งต้องมีค่ามากกว่าหรือเท่ากับเงินรวม และคำนวณเงินทอน

```text
change = expense - total
```

พิมพ์จำนวนเงินรวมค่าสินค้าและเงินทอน (ถ้ามี)

### ฟังก์ชันที่ต้องมี

- ฟังก์ชันรับจำนวนสินค้า
- ฟังก์ชันรับราคาต่อหน่วย
- ฟังก์ชันคำนวณเงินรวม
- ฟังก์ชันคำนวณจำนวนเงินที่จ่าย
- ฟังก์ชันคำนวณเงินทอน
- ฟังก์ชันพิมพ์ผลลัพธ์

ไฟล์โปรแกรม: `01-product_total_and_change.cpp`

## ข้อ 2: คำนวณส่วนลดค่าสินค้า

จงเขียนโปรแกรมคำนวณส่วนลดค่าสินค้า โดยรับจำนวนเงินค่าสินค้า (`payment`) ซึ่งต้องมากกว่า 0 และคำนวณส่วนลด

```text
ส่วนลด = ยอดเงินค่าสินค้า * ส่วนลด / 100
```

### เงื่อนไขส่วนลด

- ยอดเงินค่าสินค้า 10,000 บาทขึ้นไป ให้ส่วนลด 10%
- ยอดเงินค่าสินค้า 5,000 บาทขึ้นไป แต่ไม่เกิน 10,000 บาท ให้ส่วนลด 5%
- ยอดเงินค่าสินค้าน้อยกว่า 5,000 บาท ไม่มีส่วนลด

### ฟังก์ชันที่ต้องมี

- ฟังก์ชันรับจำนวนเงินค่าสินค้า
- ฟังก์ชันคำนวณส่วนลด
- ฟังก์ชันพิมพ์ผลลัพธ์

ไฟล์โปรแกรม: `02-product_discount.cpp`

## ข้อ 3: นับคะแนนการเลือกตั้ง

จงเขียนโปรแกรมนับคะแนนการเลือกตั้งนายกสโมสรคณะของนักศึกษา ซึ่งมีนักศึกษาสมัครเป็นประธานคณะ 3 คน ได้แก่ หมายเลข 1-3

ให้รับจำนวนผู้ที่ใช้สิทธิ์ทั้งหมด (`total`) ซึ่งต้องมากกว่า 0 และรับหมายเลขที่นักศึกษาเลือก (`number`) ทีละคน หากหมายเลขที่นักศึกษาเลือกไม่ใช่หมายเลข 1-3 ให้นับเป็นบัตรเสีย

เมื่อนับคะแนนเสร็จ ให้พิมพ์ผลลัพธ์คะแนนที่ได้ของแต่ละหมายเลข และจำนวนบัตรเสียออกมา

### ฟังก์ชันที่ต้องมี

- ฟังก์ชันรับจำนวนผู้ใช้สิทธิ์ทั้งหมด
- ฟังก์ชันรับหมายเลขที่นักศึกษาเลือกและนับคะแนน
- ฟังก์ชันพิมพ์ผลลัพธ์

ไฟล์โปรแกรม: `03-election_vote_count.cpp`

## ข้อ 4: คำนวณคะแนนสอบและตัดเกรด

จงเขียนโปรแกรมคำนวณคะแนนสอบและตัดเกรด โดยรับคะแนนเต็มการสอบกลางภาค (`totalMidterm`) และคะแนนเต็มของการสอบปลายภาค (`totalFinal`) คะแนนสอบกลางภาค (`midtermScore`) และคะแนนสอบปลายภาค (`finalScore`)

คะแนนทั้งหมดต้องมีค่าไม่น้อยกว่า 0 และคะแนนสอบต้องไม่มากกว่าคะแนนเต็ม จากนั้นคำนวณคะแนนสอบสุทธิ

```text
netScore = (midtermScore + finalScore)
           / (totalMidterm + totalFinal) * 100
```

และตัดเกรด โดยให้กำหนดเกณฑ์ในการตัดเกรดเอง

### ฟังก์ชันที่ต้องมี

- ฟังก์ชันรับคะแนนเต็ม
- ฟังก์ชันรับคะแนนสอบ
- ฟังก์ชันคำนวณคะแนนสอบสุทธิ
- ฟังก์ชันตัดเกรด
- ฟังก์ชันพิมพ์ผลลัพธ์

ไฟล์โปรแกรม: `04-exam_score_and_grade.cpp`

## ข้อ 5: เครื่องคิดเลขอย่างง่าย

จงเขียนโปรแกรมเครื่องคิดเลขอย่างง่าย ให้มีการบวก (`+`) ลบ (`-`) คูณ (`*`) หาร (`/`) และหารเอาเศษ (`%`)

โดยกำหนดเป็นเมนูให้เลือก และรับตัวเลือกจากคีย์บอร์ด ซึ่งตัวเลือกจะต้องเป็นค่าที่กำหนดไว้ในเมนูเท่านั้น จากนั้นรับจำนวนเต็มจากคีย์บอร์ด 2 ค่า เพื่อประมวลผลตามเมนูที่เลือก และพิมพ์ผลลัพธ์ออกมา

### ฟังก์ชันที่ต้องมี

- ฟังก์ชันสร้างเมนูและรับตัวเลือกจากคีย์บอร์ด
- ฟังก์ชันรับจำนวนเต็ม 2 ค่า
- ฟังก์ชันประมวลผลตามเมนูที่เลือก
- ฟังก์ชันพิมพ์ผลลัพธ์

ไฟล์โปรแกรม: `05-menu_calculator.cpp`

## ข้อ 6: คำนวณพื้นที่และเส้นรอบวงด้วยเมนู

- ฟังก์ชันประมวลผลตามเมนูที่เลือก
- ฟังก์ชันพิมพ์ผลลัพธ์
