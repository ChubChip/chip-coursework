## ข้อ 1: ตัดเกรดจากคะแนนสอบกลางภาคและปลายภาค

จงเขียนโปรแกรมตัดเกรดนักศึกษาจากคะแนนสอบกลางภาค ซึ่งมีคะแนนเต็ม 40 คะแนน และคะแนนสอบปลายภาค ซึ่งมีคะแนนเต็ม 60 คะแนน ดังนี้

- รับข้อมูลคะแนนสอบกลางภาคจากคีย์บอร์ด โดยตรวจสอบความถูกต้องของคะแนนสอบ คือต้องมีค่าตั้งแต่ 0-40 เท่านั้น หากไม่ถูกต้องให้รับใหม่จนกว่าจะถูกต้อง
- รับข้อมูลคะแนนสอบปลายภาคจากคีย์บอร์ด โดยตรวจสอบความถูกต้องของคะแนนสอบ คือต้องมีค่าตั้งแต่ 0-60 เท่านั้น หากไม่ถูกต้องให้รับใหม่จนกว่าจะถูกต้อง
- นำคะแนนสอบกลางภาคและคะแนนสอบปลายภาคมารวมกัน และตัดเกรดตามเกณฑ์ต่อไปนี้
- พิมพ์ผลลัพธ์คะแนนรวมและเกรดออกมา

### เกณฑ์การตัดเกรด

## ข้อ 2: คำนวณพื้นที่และเส้นรอบวง

จงเขียนโปรแกรมคำนวณพื้นที่สามเหลี่ยม (triangle) พื้นที่สี่เหลี่ยม (rectangle) พื้นที่วงกลม (circle) และเส้นรอบวง (circumference) ดังนี้

```text
triangle = (width * height) / 2
rectangle = width * height
circle = PI * radius * radius
circumference = 2 * PI * radius
```

โดย `PI` มีค่าเท่ากับ `22/7` หรือ `3.14159`

ให้ใช้ loop รับตัวเลือกจากคีย์บอร์ด ดังนี้

- หากตัวเลือกเป็น `1` หมายถึงต้องการคำนวณพื้นที่สามเหลี่ยม ให้รับ `width` และ `height` จากคีย์บอร์ด จากนั้นคำนวณพื้นที่สามเหลี่ยม และพิมพ์ผลลัพธ์ออกมา
- หากตัวเลือกเป็น `2` หมายถึงต้องการคำนวณพื้นที่สี่เหลี่ยม ให้รับ `width` และ `height` จากคีย์บอร์ด จากนั้นคำนวณพื้นที่สี่เหลี่ยม และพิมพ์ผลลัพธ์ออกมา
- หากตัวเลือกเป็น `3` หมายถึงต้องการคำนวณพื้นที่วงกลม ให้รับ `radius` จากคีย์บอร์ด จากนั้นคำนวณพื้นที่วงกลม และพิมพ์ผลลัพธ์ออกมา
- หากตัวเลือกเป็น `4` หมายถึงต้องการคำนวณเส้นรอบวง ให้รับ `radius` จากคีย์บอร์ด จากนั้นคำนวณเส้นรอบวง และพิมพ์ผลลัพธ์ออกมา
- หากตัวเลือกอื่นๆ ที่ไม่ใช่ `1-4` แสดงว่าไม่ต้องการคำนวณค่าใดๆ ให้หยุดการวน loop และจบการทำงาน
