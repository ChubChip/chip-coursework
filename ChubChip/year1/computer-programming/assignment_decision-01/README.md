# Decision Assignment I

## ข้อ 1

จงเขียนโปรแกรมรับตัวอักษร 1 ตัว จากนั้นตรวจสอบว่าตัวอักษรที่รับมาเป็นตัวอักษร A หรือไม่ ถ้าใช่ให้แสดงคำว่า `"Is A"` แต่ถ้าไม่ใช่ให้แสดง `"Not A"`

### Input

- ตัวอักษร 1 ตัว

### Output

- `Is A` หากตัวอักษรที่รับเข้ามาคือ `A`
- `Not A` หากตัวอักษรที่รับเข้ามาไม่ใช่ `A`

ไฟล์โปรแกรม: `01-check_character_a.cpp`

## ข้อ 2

จงเขียนโปรแกรมรับราคาขาย และราคาทุน หากราคาขายได้มากกว่าราคาทุน ให้แสดงผลลัพธ์เป็น `"profit"` มิฉะนั้น ให้แสดงผลลัพธ์เป็น `"loss"`

### Input

- ราคาขาย
- ราคาทุน

### Output

- `profit` หากราคาขายมากกว่าราคาทุน
- `loss` หากราคาขายไม่มากกว่าราคาทุน

ไฟล์โปรแกรม: `02-profit_or_loss.cpp`

## ข้อ 3

จงเขียนโปรแกรมรับจำนวน 2 จำนวน นำมาบวกกัน ถ้าผลบวกมากกว่า 50 แสดงคำว่า `"More 50"`

### Input

- จำนวนเต็ม 2 จำนวน

### Output

- `More 50` หากผลบวกของจำนวนทั้งสองมากกว่า 50

ไฟล์โปรแกรม: `03-sum_more_than_50.cpp`

## ข้อ 4

จงเขียนโปรแกรมรับจำนวน 2 จำนวน นำมาบวกกัน หากผลบวกมีค่า 60 ขึ้นไป ให้แสดงคำว่า `"Pass"` หากผลบวกต่ำกว่า 60 ให้แสดงคำว่า `"Fail"`

### Input

- จำนวนเต็ม 2 จำนวน

### Output

- `Pass` หากผลบวกมีค่าตั้งแต่ 60 ขึ้นไป
- `Fail` หากผลบวกมีค่าต่ำกว่า 60

ไฟล์โปรแกรม: `04-sum_pass_or_fail.cpp`

## ข้อ 5

จงเขียนโปรแกรมรับตัวเลข 1 ตัว หากเป็น 1 ให้พิมพ์ `"Yes"` หากเป็น 0 ให้พิมพ์ `"No"` นอกเหนือจากนั้น ให้พิมพ์ `"Error"`

### Input

- ตัวเลข 1 จำนวน

### Output

- `Yes` หากค่าที่รับเข้ามาเป็น `1`
- `No` หากค่าที่รับเข้ามาเป็น `0`
- `Error` หากค่าที่รับเข้ามาไม่ใช่ `1` หรือ `0`

ไฟล์โปรแกรม: `05-check_one_or_zero.cpp`
