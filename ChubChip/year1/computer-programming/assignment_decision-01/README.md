# Decision Assignment 1

แบบฝึกหัดเกี่ยวกับการใช้คำสั่งตัดสินใจในภาษา C/C++

## แบบฝึกหัดที่ 1: ตรวจสอบตัวอักษร A

รับตัวอักษรจากคีย์บอร์ด แล้วตรวจสอบว่าตัวอักษรที่รับเข้ามาคือ `A` หรือไม่

### Input

- ตัวอักษร 1 ตัว

### Output

- `Is A` เมื่อตัวอักษรที่รับเข้ามาคือ `A`
- `Not A` เมื่อตัวอักษรที่รับเข้ามาไม่ใช่ `A`

ไฟล์โปรแกรม: `01-check_character_a.cpp`

## แบบฝึกหัดที่ 2: ตรวจสอบกำไรหรือขาดทุน

รับราคาขายและราคาทุนจากคีย์บอร์ด แล้วเปรียบเทียบว่าราคาขายมากกว่าราคาทุนหรือไม่

### Input

- ราคาขายสินค้า
- ราคาทุนสินค้า

### Output

- `pofit` เมื่อราคาขายมากกว่าราคาทุน
- `loss` เมื่อราคาขายไม่มากกว่าราคาทุน

ไฟล์โปรแกรม: `02-profit_or_loss.cpp`

> หมายเหตุ: ในโค้ดต้นฉบับใช้คำว่า `pofit`

## แบบฝึกหัดที่ 3: ตรวจสอบผลรวมมากกว่า 50

รับตัวเลขจำนวนเต็ม 2 จำนวนจากคีย์บอร์ด แล้วนำมาบวกกัน จากนั้นตรวจสอบว่าผลรวมมากกว่า 50 หรือไม่

### Input

- Number 1
- Number 2

### Output

- `more 50` เมื่อผลรวมของตัวเลขทั้งสองมากกว่า 50

ไฟล์โปรแกรม: `03-sum_more_than_50.cpp`

## แบบฝึกหัดที่ 4: ตรวจสอบค่า 1 หรือ 0

รับตัวเลขจากคีย์บอร์ด แล้วตรวจสอบค่าที่รับเข้ามา

### Input

- ตัวเลข 1 จำนวน

### Output

- `Yes` เมื่อรับค่าเป็น `1`
- `No` เมื่อรับค่าเป็น `0`
- `Error` เมื่อรับค่าอื่นนอกเหนือจาก `1` และ `0`

ไฟล์โปรแกรม: `04-check_one_or_zero.cpp`

- การเปรียบเทียบตัวอักษรด้วย `strcmp`
